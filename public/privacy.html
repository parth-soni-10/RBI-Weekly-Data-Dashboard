Privacy

What this dashboard keeps, and where

The RBI Weekly Dashboard has no accounts, no advertising and no analytics or tracking scripts. There is no form that collects personal data. This page lists the little the site does handle.

Last updated: 21 October 2026

  • CookiesNone
  • AnalyticsNone
  • AccountsNone
  • Server-side stateData cache only

What stays in your browser

The dashboard remembers your choices locally so the page opens where you left it: rbi-theme (light or dark), rbi-macro (whether the macro panel is expanded), and a merged-data cache written by the reload button so repeat reloads do not re-scrape weeks it already has. A service-worker cache stores the app shell and the last data files so the last week still renders when you are offline.

None of that is sent to this site as personal data, and none of it identifies you. Clearing site data, or using a private window, removes all of it.

What the server keeps

There is no account system, no newsletter and no contact form. The only durable server-side state is a cache of figures the dashboard itself fetched — the merged weekly rows and a few macro series — held in a Cloudflare KV namespace so a reload does not re-scrape the same weeks. It holds numbers and timestamps, not visitors: no IP addresses, no user agents and no identifiers are written to it.

Requests to third parties

Reserves and macro series are fetched by this site's own server-side functions, so your browser does not contact RBI, NSDL, NSE, BSE, PPAC, the World Bank or Yahoo Finance for them, and those providers do not see your IP address from those requests. Fonts, scripts and styles load only from this domain. Following a source link takes you to that provider, under its own privacy policy.

Hosting and logs

The site is hosted on Cloudflare Pages, which processes requests and keeps standard operational logs — IP address, user agent, requested URL and timestamp — as any web host does, for security and reliability. This project does not build profiles from them, combine them with anything else, or sell or share data. There is no third-party embed on any page.

Cookies and consent

This site sets no cookies and runs no consent banner, because there is nothing to consent to: no analytics, no advertising identifiers, no cross-site tracking. The only client-side storage is the local preferences and offline cache described above, which exist to make the page work.

Your rights

Under the GDPR you may ask for access, correction or erasure of personal data, and you have the right to complain to the Irish Data Protection Commission. Questions about this page, or a removal request, can go to soni.soni.parth@gmail.com. If this notice changes, the date at the top changes with it.
