Source code and issue tracker

The site is open source at github.com/parth-soni-10/RBI-Weekly-Data-Dashboard. A scraper that broke, a table that parsed into the wrong column, or a feature request can be filed there as an issue - that keeps the discussion next to the parser that would change, and it is the fastest route for anything reproducible.

Reporting a data problem well

Include four things and no round trip is needed to reproduce it:

  • The metric - for example foreign currency assets, gold, USD/INR, FII equity net, the 10-year G-Sec yield.
  • The date - the WSS Friday, or the month/quarter for a macro series.
  • Both values - what the dashboard shows and what the source shows, with the unit.
  • The source link - the RBI/NSDL/PPAC/World Bank page or file you compared against.

A screenshot is welcome but a link and the two numbers are what make it fixable. If the dashboard says static fallback, that already tells you the value is curated or last-known rather than freshly scraped - a source link showing a newer figure is exactly the report that helps.

What this site cannot do

It cannot answer an RBI query, correct a figure at the source, or give investment, tax or legal advice. If a figure differs from RBI's own publication, RBI is right - the dashboard is a transcription. Send the link and the row and the transcription will be fixed.

Before writing: the latest week's figure is on the homepage, and every series is also available as JSON - /data/latest.json and /data/forex-weekly.json are the quickest way to quote the exact value you are questioning.
