# RBI Weekly Dashboard - Project Instructions

## Overview
Static dashboard of India's RBI Weekly Statistical Supplement (forex reserves, gold, rupee spot, equity markets), live crude-oil import estimates, macro context tiles (FII flows, G-Sec yield, REER, FX intervention, tax, a composite India Fear & Greed sentiment meter), a "world's biggest borrower countries" ranking (World Bank QEDS, India highlighted), and a curated PM CARES Fund section. Served from Netlify: a single-file frontend in `public/` plus serverless scrapers.

## Tech Stack
- Language: JavaScript (Node >= 18), zero build step, vanilla HTML/CSS/JS frontend
- Frontend: `public/index.html` - all markup, CSS, and JS inline in one file
- PWA: `public/manifest.webmanifest` + `public/sw.js` (network-first shell, 24h-tolerant data-cache fallback so the last-known week renders offline; CDN deps are opportunistic-only) + generated icons in `public/icons/` (regenerate via `python tools/make-icons.py`) — registered only on https/localhost, install button surfaces `beforeinstallprompt`
- Charts: Chart.js 4.4.1 + GSAP 3.12.5, vendored in `public/vendor/` (three.js r128 also vendored for the 3D ridge; loaded lazily) — no CDN dependency; fonts Inter + DM Mono (Google Fonts, the only external fetch)
- Hosting: Netlify (static publish + Functions, esbuild bundler)
- Deps: `node-fetch` (^2.7), `node-xlsx` (^0.23) - both used by the scrapers
- External-debt ranking: `netlify/functions/fetch-external-debt.js` + `scripts/fetch-debt-rankings.js` → World Bank **Quarterly External Debt Statistics** (QEDS; IMF SDDS source 22 indicator `DT.DOD.DECT.CD.AR.US`, merged with GDDS source 23 `DT.DOD.DECT.CD.TL.US`) + WDI reserves (`FI.RES.TOTL.CD`, annual, latest year per economy) — api.worldbank.org, official country submissions, no key needed. Scope: SDDS/GDDS reporters INCLUDING high-income economies → USA #1 (~$30T, 2026Q1), UK #2, China #14; India ~#23 (~$763B, 2026Q1; cover ≈1.03× reserves). (The annual IDS series `DT.DOD.DECT.CD` excludes high-income reporters and tops out at China — do not mix the two.) India's maturity split comes from the SDDS short-term stock `DT.DOD.DSTC.CD.US` (long-term = total − short-term, the QEDS identity): `history` carries `total_bn`/`st_bn`/`lt_bn`/`st_share_pct` (~20% short-term). `rank_history` rebuilds India's borrower rank for every quarter since {currentYear−5} from the full QEDS panel (SDDS+GDDS date-range queries merged per quarter, ≥30 reporters; panel rows carry the ISO3 in `country.id` because `countryiso3code` is blank there) — a per-quarter rank counts that quarter's reporters (~117–124), NOT the 135 latest-vintage count the tile uses, and the newest quarter always runs slightly high while late filers report. Serves `top_borrowers` (12, each with `reserves_bn`/`reserves_year`), `india` (rank + ±2 rank `neighbours` + quarterly `history`), `reserves_year`/`reserves_note`, `scope_note`; 6h in-process memo, `?refresh=1` busts it (frontend uses that on Reload), curated FALLBACK_* arrays (verified 2026-09-11) when the API fails
- Scheduling: GitHub Actions cron (`refresh-data.yml`, daily 00:30 UTC)

## Code Style
- File naming: kebab-case. `fetch-*.js` = scrapers used by the dashboard; `data-*.js` = public JSON APIs behind `public/_redirects`
- Scrapers never throw to the client: always return 200, degrade to curated fallbacks, and flag them with `status: static fallback` / `source` / `as_of_date` fields so the UI can say "fallback" honestly
- Scrapers try multiple upstream sources in order (e.g. several Yahoo tickers for G-Sec) and never fail hard
- Heavy scrapers memoize via `_utils/cache.js` `withCache(key, ttlMs, fn)` (in-memory, fail-open) and set `Cache-Control`; light ones set plain headers in a `CORS` object
- Shared HTTP helpers live in `_utils/http.js` (`get`, `extractHtmlTables`, `parseNum`, `UA`)
- Frontend: semantic class names over inline styles; `.section` blocks are the tab panes, `showSection()`/`sw()` drive tabs and permalink hash (`#tab=...&modes=...`); empty metric values render as `—` (deliberate convention)
- Data file uses ISO dates (`YYYY-MM-DD`); display uses `en-IN` formatting via `fmt()`
- End-user affordances: header quick actions (share→clipboard fallback, print/report stylesheet, install), `zoomable()` gives every vertical category-axis chart Ctrl+wheel zoom / drag-pan / pinch / dblclick-reset (handlers bound once per canvas via WeakMap, retargeted on chart rebuild; horizontal-bar and log-axis charts opt out), table range toggle 10/26/52 weeks (all three weekly tables together), full-history CSV download, reserves "1Y level" tab, `updateDocTitle()` puts the latest reserves + USD/INR in the browser tab title, 30-min auto-refresh (visible tabs only), OG/Twitter meta for share previews, and a Compare tab (`CMP_METRICS` in index.html) that diffs any two Fridays — cards + side-by-side table + CSV, permalinked via `&cmp=FROM>TO` in the hash (decoded with `decodeURIComponent` in `hashLoad`); when a live check merges a newer week, `notifyNewWeek()` slides in a toast (8s auto-dismiss, one at a time, escHtml'd) plus a persistent header badge — both jump to the dashboard and clear on click, deduped per week via `newWeekNotifiedFor`. The ⚑ Events tab draws the `MACRO_EVENTS` registry (RBI MPC + Fed; resolved decisions only — labels mirror `REPO_HISTORY` in fetch-gsec.js, while upcoming meetings live in `MPC_SCHEDULE` in the same file and render hollow on the repo chart; when a meeting resolves, append its decision to `REPO_HISTORY`, add the `MACRO_EVENTS` line, and drop the date from `MPC_SCHEDULE` — keep all three in sync) as labeled vertical rules on the rupee chart via the globally-registered `eventsPlugin` (guards on canvas id `cFx` + tab mode; inline scripts run before deferred Chart.js, so registration happens in DOMContentLoaded). `renderCompChart()` draws reserves composition (`fca_usd`/`sdr_usd`/`imf_reserve_usd` now parsed AND persisted per record by fetch-data.js — true stacked area with a sum-of-parts tooltip footer; the `share` tab plots **gold share alone across every week** (gold + total are always parsed — the continuous gold-rise line) with a dashed gold+SDR+IMF overlay on decomposition weeks, hidden until the backfill produces at least one; live-merge records never let a stale null (or a pre-column-swap-fix payload, caught by `cleanLiveRecord`'s swap/drop sanity) shadow a parsed value); decomposition-less weeks still show the stacked-area empty state); `renderMacroTrends()` plots the 1-year daily 10Y yield series (`yield_series` from fetch-gsec; older cached payloads fall back to a repo-step + current-yield line) and the REER series, `renderSpreadChart()` draws the 10Y−repo spread (the market's implied policy expectations — repo sampled stepped at each daily yield observation, segments amber above parity / blue below, zero-dash reference; computed client-side from `yield_series` + `repo_history`), and `renderRepoChart()` draws the repo MPC path as a true step chart (plateau between meetings, extends to today, diamond markers colored cut/hold/hike) then carries the in-force plateau through fetch-gsec's `mpc_schedule` — RBI's published upcoming meeting dates (decision = meeting's last day), drawn as hollow amber diamonds with a card-surface fill so they punch a clean hole in the line (grey would read as a hold); tooltip "Next MPC decision — repo X% in force until then"; entries at/before the newest decision are ignored (stale schedule can't draw markers) and a meeting landing today keeps its marker instead of a duplicate axis label; payloads without `mpc_schedule` (old caches) render exactly as before — with the US Fed funds (FRED DFEDTARU csv) and ECB main refinancing (ECB SDMX API, change-dates series) rates as faint dashed comparison lines — sampled at each MPC decision date (`policy_peers` in the fetch-gsec payload, both sources fail-open and timeout-raced so they never delay the payload; empty steps just skip the dataset) — both registered in `charts` for PNG export; `renderFngGauge(macroData.fng)` draws the Fear & Greed half-gauge + per-signal bars (`fngColor()` returns theme-paired zone palettes — 500-series on dark, 600-series on light, both ≥3:1); `renderFngHistory()` plots the committed daily composite from `public/sentiment-history.json` (zone bands + 50-midline; one point per day, 400-day window, empty state under 2 points). PNG export via `dlChartPNG()` composites onto the theme surface; weekly tables have a date-range filter (`rangeFiltered()` wins over the 10/26/52 cap) + sticky theads; keys 1–5 switch tabs (ignored while typing); `updatePrintVintage()` fills the print-only provenance footer; the status pill doubles as a data-freshness readout (`markDataFresh`/`renderFreshness`: after every successful load the status text becomes a ticking age — "just now" → "5m ago" — amber past 26h via `.stale`, exact time in the tooltip, `#fresh-text` compact mirror on dot-only ≤430px phones, failed loads never re-stamp freshness); `scripts/make-rss.js` (in `npm run fetch:data` + `npm run rss`) writes `public/feed.xml` (26 items). netlify.toml ships CSP + XFO/nosniff/Referrer-Policy/Permissions-Policy and long-caches /vendor/* + /icons/*

## Testing
- No test framework exists. Run `npm run check` (node --check on every server file) after touching any `.js`
- Frontend changes: verify by serving `public/` and loading the page - tables/charts render from `rbi-data.json`; macro + crude tiles need the Netlify functions (use `netlify dev` or accept graceful fallbacks locally)

## Build & Run
- Regenerate static data: `npm run fetch:data` (incremental - only fetches weeks newer than the newest record in `public/rbi-data.json`) and `npm run fetch:debt` (rewrites `public/external-debt.json` from the live World Bank API; fails open to the curated fallback, never deletes the file). Both run in the deploy build AND the daily cron, so every run re-pulls the sources. `node scripts/backfill-decomp.js` one-shots the WSS decomposition fields (fca/sdr/imf/gold_tonnes) into historical records (only fills missing, ±0.5% sum sanity gate, `--dry-run`/`--limit N`, persists per week); it lives in the daily cron until the backlog is filled and is a no-op afterwards. RBI's doc CDN (rbidocs) fronts an intermittent F5 limiter that serves a challenge HTML page instead of the file — the script detects it via magic bytes, paces 5s/week, cools down 20s, aborts after three consecutive challenges, and lets later runs resume; exit code stays 0 so a hot limiter never breaks the cron
- The dashboard's **Reload data** button loads `rbi-data.json`, then live-checks `/.netlify/functions/fetch-data` for weeks newer than the file's newest record (walking `?weekOffset=` pages) and merges them in-memory; the merged set is persisted via `/.netlify/functions/data-sync` (Netlify Blob) and restored on the next reload, so repeat reloads never re-scrape the same weeks. The blob also stores the newest official forward figure found (`forward` key, with `checkedAt`; reused while under 3 days old), per-range EM-peers payloads (`em` key, with per-range `fetchedAt`; reused while under 12h old), and a durable mirror of the curated PM CARES rows (`pmcares` key — the inline `PMCARES` array stays the source of truth; the blob copy is a defensive fallback). Writes that omit a key preserve the existing saved value, so the weekly/forward/em/pmcares persists never clobber each other. It also refreshes all macro cards (FII flows/history, G-Sec, tax, REER, forward source — `fetchAllMacro` with the HTTP cache busted), live-checks the forward book via `/.netlify/functions/fetch-fwd-latest` (re-runs the Bulletin Table 4A discovery/parse from `scripts/update-fwd-monthly.js`, appends in-memory when newer than the series tail), and busts the EM-peers per-range cache (`fetch-em-peers` refetches the active range). The heavy crude-oil tile (`fetch-crude`) also refreshes on an explicit Reload click — fire-and-forget in the background so it never blocks the other checks, capped to one successful live-check per hour per session (`CRUDE_CHECK_MIN_MS`; skipped reloads log and keep the tile, failures never arm the cap; the initial page load skips it to avoid a double scrape). Falls back to file-only when the functions aren't deployed (local preview)
- Syntax check: `npm run check`
- Local dev: serve `public/` with any static server; live functions require `netlify dev`
- Deploy: Netlify (build command `npm run fetch:data` regenerates data on every deploy); the GitHub Action keeps `rbi-data.json` fresh between deploys

## Conventions
- Git: work on `main`; commit messages are imperative one-liners (e.g. "Speed up load, add collapsible header + animated mobile nav"). No PR workflow - commits go straight to main
- Do not commit `public/rbi-data.json` manually unless it's the intentional baseline; the Action owns refreshes
- PM CARES data is curated (audited PDFs are scanned images, not scrapable) - it lives in the `PMCARES` array in `index.html`, not in the pipeline
- RBI's net forward position (`fetch-fx-intervention.js`) is AUTO-UPDATED, not hand-curated: month-end figures (Mar-21 → today, all 65 months) come from the RBI Bulletin's Current Statistics table 4A "Maturity Breakdown (by Residual Maturity) of Outstanding Forwards of RBI", a server-rendered BS_ViewBulletin page — `scripts/update-fwd-monthly.js` reads the newest issue on every deploy/daily cron and appends/upgrades `FWD_SERIES` (its `--backfill` flag walks every issue back to May-2021 to fill or verify gaps). `scripts/update-fwd-series.js` does the same for the Mar/Sep half-yearly FX reserves report anchors, which WIN over the Bulletin table at the same date (RBI revised some early figures — Sep-2021 is +49.61bn in the Nov-21 Bulletin but +49.11bn in the report and later Bulletins). Both fail open (slow/blocked RBI never breaks a deploy) and never delete entries. The macro tile, the reserve KPIs, and the `cFwd` chart read the series automatically — chart tabs: stepped weekly on the dashboard's own WSS Fridays, stepped weekly every Friday since 2021 (long-to-short flip + Oct-23 short dip), and every published figure as points
- Keep inline `style=""` out of new markup; add classes to the stylesheet instead
- The borrower tiles/chart live on `debtData` (loaded by `loadExternalDebt` inside `fetchAllMacro`, static-file fallback `external-debt.json` for local previews), NOT in `macroData`; rendered by `renderExternalDebt()`/`renderDebtChart()` with tab group `debt` (top/india/cover/maturity/rank/history) wired through `sw()`; the `rank` tab inverts the y-axis (#1 on top) and lists each quarter's ±2 rank neighbours in the tooltip. Debt cover = external debt ÷ FX reserves: India's tile uses the dashboard's own fresher RBI weekly reserves (`records`) via `debtCoverRatio()`, falling back to the WDI annual figure; the `cover` chart tab plots cover ratios on a LOG x-axis (financial hubs like Luxembourg ~1300× / Ireland ~280× would crush a linear scale) with India's ratio as a dashed amber line dataset. `updateUI()` re-renders the tile after records load so the RBI figure replaces the WB one

## Icons (Lucide)
- Icons come from a vendored copy of Lucide (`public/lucide.min.js`, pinned 0.462.0). Add `<i data-lucide="name"></i>` to markup; `lucide.createIcons()` runs at end of `<body>`.
- Icon lookup keys are PascalCase at runtime (`data-lucide="ship"` → `Ship`). Not every Lucide name exists in this pinned build — verify an icon name against `lucide.icons` before using it (e.g. `barrel` and `droplets` do NOT exist here; `ship`, `fuel`, `factory`, `hand-heart`, `table-2` do).
- The Reload button re-injects its icon after load: `btn.innerHTML = '<i data-lucide="rotate-cw"></i> Reload data'` then re-runs `lucide.createIcons()`.
- Size icons via the `.lucide` rules at the bottom of the inline `<style>` (in nav/status/btn/dl/tab). SVGs inherit `currentColor`.
